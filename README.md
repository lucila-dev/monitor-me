# Monitor Me

## What it does

Monitor Me is a desktop system monitor. It tracks live CPU, memory, disk, network, and battery usage, shows running processes, stores performance history, and alerts you when resource usage stays high. It also displays storage by partition, network interface status, and lets you copy a system diagnostic report.

## Tech stack

- Python 3.9+
- PySide6
- psutil
- SQLite
- PyInstaller
